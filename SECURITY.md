# Security policy

Cabane opens files that may come from untrusted sources (projects, furniture libraries, 3D models) and stores API keys for AI providers. Security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public discussion** for a security issue.

Report it privately through GitHub: **Security → Report a vulnerability** on this repository ([private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)).

Include, if possible:
- the affected version;
- the steps or the file needed to reproduce the issue;
- the impact you observed or expect.

You will get an acknowledgement as soon as possible. Fixes are released as new versions, and the advisory is published once users can update.

## Supported versions

Cabane is in early development. Only the latest release receives security fixes.
